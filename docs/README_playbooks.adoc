== Example playbooks

To use Men&Mice Micetro Ansible Integration you need to create Ansible
playbooks that utilize the functionality of Men&Mice Micetro.

Following are a couple of example playbooks for inspiration.

Correctness is verified by the automated test suites under `tests/unit`
(mocked, run on every change) and `tests/functional` (exercises the real
modules/lookups/inventory plugin against a live Micetro host via
`ansible-playbook`/`ansible-inventory`; see `CLAUDE.md` for how to run
it). Confirmed working against a live Micetro 26.1.1 instance on
ansible-core 2.16.

All these playbooks are available in the `examples` directory.
